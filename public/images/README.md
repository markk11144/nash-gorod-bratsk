# Изображения сайта

- `hero-city.webp` — оригинальная иллюстрация, созданная для этого проекта с помощью встроенного генератора изображений OpenAI 16.07.2026. Это художественный образ северного города у воды, а не документальная фотография Братска.
- Не заменяйте заглушки команды фотографиями из 2ГИС, Домклик или социальных сетей без разрешения владельца изображения.
- После получения официальных фотографий сохраните оптимизированные WebP/AVIF-файлы в этой папке и обновите `src/data/team.ts` и компонент команды.
- Рекомендуемый размер фото сотрудника: 900×900 px, нейтральный фон, письменное согласие на публикацию.

Промпт hero-иллюстрации зафиксирован в `SOURCES.md`.
